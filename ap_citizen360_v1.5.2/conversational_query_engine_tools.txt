1. LLM AGENT MCP TOOLS (EXPOSED TO LANGGRAPH)
-------------------------------------------------------------------------------
Tool Name           : retrive_schema_rag
MCP Server Script   : MCP/mcp_rag.py
Role / Function     : Vector retrieval of relevant SQL table schemas & DDLs 
                      from Milvus 'schema_store' partition.

Tool Name           : search_documents
MCP Server Script   : MCP/mcp_rag.py
Role / Function     : Vector similarity search over unstructured PDF, DOCX, and
                      TXT passages in Milvus 'document_store' partition.

Tool Name           : execute_sql
MCP Server Script   : MCP/mcp_sql_execution.py or MCP/mcp_hive_execution.py
Role / Function     : Executes SQL queries against SQLite or Impala/Hive 
                      databases and returns formatted JSON rows.
